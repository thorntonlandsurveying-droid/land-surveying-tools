Privacy Policy

Last updated: October 15, 2026

This policy applies to Land Surveying Tools, including the TLS GTD Dashboard, a private tool operated by Thornton Land Surveying (University Place, Washington). The tool is used only by its owner and is not offered to the public.

What the tool accesses

When the owner chooses to sign in with Google, the tool requests read-only access to Google Tasks (scope https://www.googleapis.com/auth/tasks.readonly). It reads task titles, notes, due dates, links and identifiers from the one task list the owner selects.

How the data is used

Imported tasks are copied into the owner's personal dashboard file on the owner's own computer and cloud-synced folder. The data is used only to help the owner organize their own work. It is not used for advertising, profiling or any other purpose.

Storage and sharing

The tool runs on the owner's computer and has no server of its own. Sign-in tokens are stored only on that computer. Google user data is not sold, shared with or transferred to any third party, and is not used to train AI or machine-learning models. The tool does not modify, complete or delete anything in Google Tasks.

Retention and revoking access

Imported items stay in the dashboard until the owner deletes them. The owner can revoke access at any time at myaccount.google.com/permissions and can delete the local sign-in file.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
